## 修复 bug：主题切换后首页 Hero 标题变黑字

- **现象**：深色 → 浅色切换后，首页 Hero 横幅"你好，下午好…"标题/副标题变黑字（浅色主题默认文字色），与深色渐变背景不协调。
- **根因**：HeroBanner 背景是固定深色渐变、文字硬编码白色，但 qfluentwidgets 主题切换会**重置其控件（TitleLabel/CaptionLabel）的样式表**为当前主题默认色（浅色=黑字），覆盖 HeroBanner 的白色实例样式。直接监听 `qconfig.themeChanged` 不够——qfluentwidgets 内部控件在 import 时就连了该信号，连接顺序在 HeroBanner 之后，导致白色恢复后又立即被控件刷新覆盖。
- **修复**：`gui_qt/components/design_system.py` HeroBanner 把文字样式提取为 `_apply_text_styles()`，监听 **`qconfig.themeChangedFinished`**（qfluentwidgets 控件刷新完成后才触发），此时恢复白色样式不会再被覆盖。
- **验证**：offscreen 实测 light→dark→light 三态标题/副标题均保持白色（含 `#FFFFFF` / `255,255,255`）；ruff All checks passed；pytest 119 passed。
- **经验**：qfluentwidgets 控件样式表会被主题切换重置；若需实例级强制样式，应监听 `themeChangedFinished`（而非 `themeChanged`）以保证在控件刷新之后应用。

## 修复 bug：主题切换"点两次才生效 + 切换很慢"

- **根因 1（点两次）**：`gui_qt/components/sidebar.py` 主题按钮 `_cycle_theme` 用 `QTimer.singleShot(150, ...)` 人为延迟 150ms 才真正 `set_mode`。期间用户再点一次，`current_mode()` 仍是旧值、`nxt` 再推进一档 → 两次点击实际切了两档（如 跟随系统→深色 跳过浅色），且每次都带延迟，体感"点了没反应、再点才动"。

- **修复**：
  1. `sidebar.py`：去掉 `QTimer.singleShot(150)`，点击立即切换（`_cycle_theme` 直接调 `_do_theme_switch`）；移除 QTimer import
