滚轮一格即时滚动（修复前 0px / 400ms 动画）

修复：页面功能区滚轮滚动慢（用户反馈）

根因
功能面板继承 qfluentwidgets ScrollArea，且为懒加载——晚于启动时的滚动优化才构建，其平滑滚动代理保持 LINEAR 模式：每次滚轮事件进入 400ms 逐帧动画引擎，滚一格要 400ms 才滚完（慢一拍）；侧边导航启动时已被优化所以流畅。
修复
新增 apply_fast_scroll(root)：处理滚动区域自身 + 全部嵌套区域，切换为 NO_SMOOTH 原生即时滚动（像素级）；面板基类构建后、懒加载页面构建后自动应用；滚轮加速器增加"首次滚轮现场优化"兜底，任何新建弹窗/对话框无需手动接线。实测滚一格即时滚动 60px（修复前 0px）。
对比修复前（LINEAR 动画）修复后（NO_SMOOTH 原生）
滚轮一格立即滚动量0px（动画吸收）60px（即时）
连续滚动跟手度每格滞后 400ms逐格即时响应
