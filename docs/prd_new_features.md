# 格式大师 FormatMaster — 新功能需求文档

## 目标
基于现有格式转换 + 工具箱的能力，扩展实用功能，保持工具型定位，不做臃肿的大而全。

---

## 1. OCR 文字识别

**现状**: `core/ocr_tool.py` 已经写好但没接进界面
**方案**: 新增一个 OCR 面板，拖入图片或 PDF → 识别文字 → 复制或导出

| 功能 | 说明 |
|------|------|
| 图片 OCR | 拖入 JPG/PNG/BMP/WEBP/TIFF 来识别里面的文字 |
| PDF OCR | 对 PDF 逐页识别，输出可搜索的 PDF 或纯文本 |
| 语言选择 | 中文简体/繁体、英文、日文、韩文等（基于 PaddleOCR） |
| 导出 | 复制到剪贴板、导出为 TXT/Word/可搜索 PDF |

---

## 2. PDF 按页提取 / 拆分增强

**现状**: PDF 拆分只能按页码范围拆成一个文件
**方案**: 新增"按页提取"模式，把选中的页码提取成多个单独的 PDF

| 功能 | 说明 |
|------|------|
| 每页一个文件 | 每一页存为一个独立的 PDF |
| 按范围提取 | 输入"1,3,5-8"提取到单个 PDF |
| 选中页面另存 | 在可视化编辑器里选中页面 → 另存为新 PDF |

---

## 3. 图片批量水印

**现状**: 图片转格式时有一个简单的文字水印，功能很弱
**方案**: 独立的图片水印面板，支持文字和图片水印批量叠加

| 功能 | 说明 |
|------|------|
| 文字水印 | 字体/字号/颜色/透明度/旋转角度/位置 |
| 图片水印 | 叠加 PNG 透明图，可调位置/缩放/透明度 |
| 批量处理 | 选定多张图片，统一参数一次输出 |
| 预览 | 单张实时预览水印效果 |

---

## 4. 批量重命名增强

**现状**: 只支持 {n} {name} {date} 三种模板变量
**方案**: 增加更多规则和实时预览

| 功能 | 说明 |
|------|------|
| 更多变量 | {original} {ext} {n:04d} {date:YYYYMMDD} {time} {folder} |
| 查找替换 | 输入查找的文字 + 替换成什么 |
| 序号控制 | 起始序号、步进、位数 |
| 大小写转换 | 全大写/全小写/首字母大写 |
| 实时预览 | 修改规则后立即显示新旧文件名对比 |

---

## 5. 音视频批量处理队列

**现状**: 一次只能转换当前的列表
**方案**: 任务队列管理，支持按顺序或并行处理多个作业

| 功能 | 说明 |
|------|------|
| 作业队列 | 添加多个不同的转换任务，依次执行 |
| 暂停/恢复 | 暂停队列，恢复继续 |
| 历史记录 | 已完成的任务列表，可以重新执行 |
| 完成后操作 | 关机/休眠/弹出通知 |

---

## 6. 文件夹自动监控（Watch Folder）

**方案**: 设置一个文件夹，新文件进来时自动按规则转换

| 功能 | 说明 |
|------|------|
| 监控目录 | 选择要监控的文件夹 |
| 转换规则 | 文件类型 + 目标格式 + 输出目录 |
| 自动处理 | 新文件出现后自动加入队列开始转换 |
| 支持类型 | 视频/音频/图片/文档 |

---

## 7. Windows 右键菜单集成

**方案**: 注册右键菜单，选中文件后直接发送到格式大师

| 功能 | 说明 |
|------|------|
| 右键发送 | 选中文件 → 右键 → "用格式大师转换" |
| 自动切面板 | 根据文件类型自动切换到对应的功能面板 |
| 文件预填 | 自动把选中的文件填进文件列表 |
| 卸载选项 | 设置里加一个按钮，一键移除右键菜单 |

---

## 8. 音频波形预览 + 裁剪

**现状**: 音频只能整体转格式，没办法裁剪片段
**方案**: 简单的波形图预览，拖动选择开始和结束时间进行裁剪

| 功能 | 说明 |
|------|------|
| 波形显示 | 用简易波形图展示音频内容 |
| 起止选择 | 拖动标记开始和结束位置 |
| 淡入淡出 | 裁剪边界可选淡入淡出效果 |
| 预览播放 | 播放选中的片段 |

---

## 9. 文件哈希校验

**方案**: 计算文件的 MD5/SHA1/SHA256，支持对比验证

| 功能 | 说明 |
|------|------|
| 单文件 | 拖入文件 → 选择算法 → 显示哈希值 |
| 批量 | 多个文件同时计算 |
| 对比 | 输入已知的哈希值，验证是否匹配 |
| 导出 | 导出哈希列表为 CSV/TXT |

---

## 10. 暗黑模式 / 主题切换

**现状**: 固定白色主题
**方案**: 浅色/暗色/跟随系统

| 功能 | 说明 |
|------|------|
| 暗黑主题 | 深灰背景 + 低饱和高亮色，覆盖所有面板 |
| 跟随系统 | 自动检测 Windows 深色模式开关 |
| 快速切换 | 侧栏底部加一个切换按钮，不需要重启 |
| 自定义色 | 用户可以改主色和高亮色 |

---

## 优先级建议

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P0 | 主题切换 | 用户感知最直接，代码改动集中在一个 D 字典 |
| P0 | OCR 接入 | ocr_tool.py 已经写好了只差界面，成本最低 |
| P1 | 批量水印 | 图片用户高频需求 |
| P1 | 重命名增强 | 已经有基础框架，扩展成本低 |
| P2 | PDF 提取增强 | 当前拆分功能太弱 |
| P2 | 哈希校验 | 独立工具不影响现有功能 |
| P3 | 波形裁剪 | 需要新依赖 |
| P3 | 监控文件夹 | 需要后台线程 + 文件系统监听 |
| P4 | 右键菜单 | 涉及 Windows 注册表 |
| P4 | 任务队列 | 改动涉及多个面板 |
